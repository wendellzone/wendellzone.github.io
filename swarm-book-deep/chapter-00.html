前言：从入门到深入

你已经读完了入门版，能跑通 Agent、看懂主循环。这本书要回答一个更深的问题——它为什么是这样设计的，以及在真实项目里怎么用。

这本书接在哪里

这是《Swarm 精读》的进阶续作。入门版带你从零理解 LLM、function calling、Agent，并逐行读完了核心库（core.py / types.py / util.py / repl.py）和 examples/basic 五个示例。

如果你还没读入门版，强烈建议先去读——本书默认你已经掌握下面这些概念，不再重复铺垫：

  • LLM 的"对话补全"、function calling 的"点单—做菜—上菜"三步。
  • Agent = 说明书（instructions）+ 工具箱（functions）+ 自动循环（run）。
  • run() 主循环：问 LLM → 判断有无 tool_calls → 执行工具 → 喂回 → 再问，直到没有工具调用。
  • handoff（交接）= 工具函数 return 一个 Agent；context_variables = 随身档案袋。
随时可以回头

左侧导航底部有「↩ 返回入门版」的链接。任何时候概念记不清了，都可以跳回去复习对应章节，再回到这里。

这本书要带你走多深

入门版回答的是"是什么、怎么写"；深度版回答的是"为什么这么设计、真实项目里怎么用、我能怎么改"。全书三部分：

第一部分 · 设计哲学与权衡（第 01–06 章）

把 Swarm 那几百行代码背后的设计决策一条条摊开来看：为什么它是"无状态"的？run() 开头为什么要 deepcopy？为什么 context_variables 靠"参数名约定"而不是显式声明？handoff 为什么设计成"返回一个 Agent"而不是配一张路由表？每一条我们都会问：换一种做法会怎样、代价是什么。

第二部分 · 进阶示例与实战（第 07–10 章）

离开玩具示例，精读 examples/ 里更接近真实项目的四个例子：航空客服的三层分诊编排、个人导购的真实数据库读写、帮助中心的 RAG 向量检索问答、以及怎么给 Agent 做自动化评测（eval）。

第三部分 · 动手改造（第 11–12 章）

最后教你亲手改造：给 Swarm 加日志/重试、接入非 OpenAI 的模型，甚至从零把 run 循环自己写一遍（mini-Swarm）。然后做一次全景收束，给出通往真实生产的路线图。

本书的一些新符号

除了沿用入门版的类比框、提示框、代码块，深度版新增了几种小组件，帮你快速抓住重点：

设计权衡盒：一眼看清"这么做 vs 换种做法"
Swarm 的选择

展示 Swarm 实际采用的做法，以及它换来的好处。

另一种做法

展示常见的替代方案，以及它的代价——帮你理解"为什么不那样做"。

陷阱盒

标注真实使用中容易踩的坑——例如"忘了把 response.messages 赋回去，Agent 就失忆了"这类。

延伸盒（可折叠）：给用过其他框架的读者

这种盒子是可选阅读。如果你用过 LangChain、LangGraph、OpenAI Agents SDK 等框架，这里会给出横向对比；如果你没用过，直接跳过完全不影响主线。默认折叠，想看再点开。

常见疑问

没读入门版，能直接读这本吗？

不建议。本书跳过了所有基础概念的铺垫，直接讨论"为什么这么设计"。如果 run 主循环、handoff、context_variables 对你还是新词，先花点时间读入门版，回报会大得多。

这本书会讲和入门版重复的代码吗？

会再次引用同一段源码，但讲的角度完全不同。入门版讲"这行代码做了什么"，深度版讲"这行代码为什么这么写、去掉它会出什么问题、生产框架会怎么改"。同一段 core.py，两本书读出的东西不一样。
