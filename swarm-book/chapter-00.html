前言与如何阅读

在正式动手之前，先花五分钟把这本书的"使用说明书"读一遍——它会告诉你这本书为谁而写、怎么读最省力。

这本书是写给谁的

如果你符合下面任意一条，那么这本书就是为你准备的：

  • 听说过"AI Agent（智能体）"这个词，但完全不知道它在代码层面到底是什么；
  • 会一点 Python（能看懂函数、字典、类），但从没写过和大语言模型（LLM）打交道的程序；
  • 想搞清楚一个 Agent 框架"到底在背后做了什么"，而不是只会调用现成的库。
一句话类比

如果说 LLM（大语言模型）是一颗聪明但只会"说话"的大脑，那么 Agent 就是给这颗大脑配上手脚、工具箱和一本岗位说明书，让它不仅能聊天，还能真正"动手办事"。这本书要讲的 Swarm，就是 OpenAI 开源的一个极简"配手脚"框架。

我们要精读的对象：Swarm

Swarm 是 OpenAI 官方放出的一个实验性、教学性质的多智能体框架。它最大的优点是——小。整个核心库只有四个文件、几百行代码：

  • swarm/types.py — 定义数据结构（Agent、Response、Result）；
  • swarm/util.py — 工具函数（把 Python 函数转成 JSON、合并流式数据）；
  • swarm/core.py — 引擎核心（run() 主循环）；
  • swarm/repl/repl.py — 一个方便的命令行交互循环。

正因为它足够小，我们才有可能把每一行代码都读懂。读懂了 Swarm，你就掌握了几乎所有 Agent 框架共通的核心套路。

重要提醒

Swarm 是官方标注的"教育用途、非生产就绪"项目（其后继者是 OpenAI Agents SDK）。我们读它不是为了拿去做产品，而是因为它像一台拆开外壳的透明发动机——最适合用来学习原理。

本书的组织方式

本书采用"概念驱动、自底向上"的路线：先补齐概念，再跑最小示例，然后一点点加特性，最后回到源码逐行精读、全景复盘。章节地图如下：

  • 第 01 章：先把 LLM、function calling、Agent 这几个词彻底讲清楚（零代码）。
  • 第 02 章：用 5 行代码跑通你的第一个 Agent。
  • 第 03 章：拆开 Swarm 的三个核心数据结构。
  • 第 04–06 章：逐个点亮 Agent 的三大能力——用工具、带记忆、会转接。
  • 第 07–09 章：钻进引擎内部，读懂 run() 主循环、流式输出与交互循环。
  • 第 10 章：把所有拼图拼成一张全景图，并指出下一步方向。

每一章长什么样

为了让你读得省力，每一章都遵循固定的七段式结构：

  1. 章首题图：大大的章号、标题和一句话导语，让你一眼知道这章讲啥。
  2. 本章目标：读完你能获得什么。
  3. 前置概念：零基础铺垫，配大量生活类比。
  4. 源码逐行精读：重点段落逐行讲"为什么这么写"，配手绘 SVG 图解。
  5. 可运行代码片段：给出完整、可复制、能真正跑起来的代码和预期输出。
  6. 常见疑问 FAQ：把你可能卡住的地方提前答掉。
  7. 小结 + 上下章导航。

怎么读最省力

阅读建议

1. 按顺序读。本书是自底向上搭积木，后一章大量依赖前一章的概念。
2. 亲手跑代码。每章的代码片段都能复制运行，点代码块右上角"复制"按钮即可。看懂 ≠ 会写，跑一遍才算数。
3. 看不懂就先记住"类比"。所有硬概念都配了生活类比，实在卡住就先抓住类比往下走，回头再补细节。

动手前的准备

如果你想边读边跑代码，需要准备两样东西（第 02 章会再详细说一遍）：

终端 · 安装与配置 
# 1. 安装 Swarm（需要 Python 3.10+）
pip install git+https://github.com/openai/swarm.git

# 2. 配置 OpenAI API Key（换成你自己的）
export OPENAI_API_KEY="sk-..."
没有 API Key 也没关系

本书大量篇幅在讲"框架本身的代码逻辑"，很多内容（比如 function_to_json 怎么把函数转成 JSON）不需要联网、不花钱也能跑。真正需要调用大模型的地方，我们会明确标注。

常见疑问

我 Python 很菜，能读懂吗？

能。你只需要认识函数、字典、列表和类的基本写法。凡是稍微进阶的语法（比如装饰器、生成器 yield、模式匹配 match），我们都会在用到时现场解释。

不学 Swarm，直接学更新的框架不行吗？

可以，但会更吃力。新框架为了"好用"包了很多层封装，反而看不清本质。Swarm 把 Agent 的核心机制（主循环、工具调用、交接）用最少的代码暴露出来，学完它，再看任何框架都会有"原来如此"的感觉。

本章小结

  • 这本书带零基础读者通过精读 OpenAI Swarm 入门 Agent 开发。
  • Swarm 的优点是极小——四个核心文件，适合逐行读懂原理。
  • 本书自底向上组织，建议按顺序读、亲手跑代码、抓住类比。
  • 准备好 Python 3.10+ 和（可选的）OpenAI API Key，就可以开始了。
